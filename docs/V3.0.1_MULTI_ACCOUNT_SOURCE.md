# Finanzas 3.0 V3.0.1 — fuente multi-cuenta

- La fuente bancaria continúa siendo estrictamente de solo lectura.
- El bridge procesa todas las pestañas que cumplen exactamente el contrato canónico de 22 columnas.
- Los movimientos se fusionan por `ID origen`.
- Si un ID aparece en varias pestañas con la misma identidad financiera (fecha, importe, identificador y producto/cuenta), prevalece la pestaña válida posterior.
- Si un ID repetido presenta una identidad financiera incompatible, la sincronización falla de forma segura y no sustituye el snapshot vigente.
- No se crea ni conserva ninguna copia adicional de los movimientos originales.
