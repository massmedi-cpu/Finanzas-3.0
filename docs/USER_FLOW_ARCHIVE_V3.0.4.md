# Flujo de usuario de Archivo

## Activos
Documentos disponibles para consulta, OCR y vinculación. La acción destructiva visible es **Mover a Archivados**.

## Archivados
Los documentos archivados siguen conservando original y metadatos. Desde aquí existen dos acciones: **Restaurar a Activos** o **Eliminar definitivamente**.

## Eliminación definitiva
Requiere confirmación explícita y sólo está disponible para documentos ya archivados. Elimina el original privado, OCR, metadatos e identificadores de vinculación documental. No modifica los movimientos bancarios de origen.
