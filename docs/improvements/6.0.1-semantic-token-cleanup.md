# Financial App 6.0.1 — retirada de aliases visuales heredados

Este bloque elimina la capa temporal de compatibilidad visual introducida durante la reforma 6.0.0.

- Todas las superficies runtime consumen directamente tokens semánticos (`--gold-primary`, `--positive`, `--negative`, `--border-*`, `--surface-*`, `--text-*`, `--radius-*`).
- `globals.css` deja de publicar aliases históricos como `--accent`, `--expense`, `--success`, `--muted`, `--surface`, `--border` o `--radius-control`.
- El audit visual recorre `app` y `components` y bloquea cualquier reintroducción de esos aliases.
- No se modifican cálculos, movimientos, importes, cuentas, documentos ni asociaciones.
