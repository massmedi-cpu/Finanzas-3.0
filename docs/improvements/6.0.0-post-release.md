# Financial App 6.0.0 — mejoras post-release

Este documento registra mejoras posteriores a la primera 6.0.0 publicada sin alterar el checkpoint de producción.

- Retirada definitiva de autenticación específica de previews.
- Smoke de producción ligado a la versión exacta desplegada.
- Paginación completa del Archivo y de la cola de revisión para evitar límites silenciosos de 200 documentos.
- Estados de carga/error alineados con la escala tipográfica mínima de 14 px.
- Migración de hojas globales residuales a tokens semánticos del sistema 6.0.0.
- Centro de control alineado con tipografía mínima y tokens semánticos.

## Bloque candidato 6.0.1 — Archivo

- Paginación server-side independiente para Nuevas, Pendientes y Archivadas.
- Búsqueda y `total` calculados con el mismo filtro para eliminar páginas fantasma.
- Histórico consultado por estado, sin cargar todos los documentos para filtrar en memoria.
- Navegación paginada de 40 documentos con búsqueda preservada entre páginas.
- Gate específico `audit-archive-v601` que prohíbe mutaciones de documentos o movimientos en esta migración de lectura.

Estas mejoras no modifican movimientos, importes, cuentas, documentos ni asociaciones financieras. La migración 6.0.1 no se aplica a Supabase hasta superar CI y validación de contrato.
