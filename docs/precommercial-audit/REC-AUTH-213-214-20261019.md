# REC-AUTH-213/214 · callback Google sin éxito falso tras pérdida de sesión

19/10/2026. Financial App PR #619 DRAFT, sin operaciones de banco ni cambios a Google.

## Hallazgo
La vista diagnóstica recibe ?google=connected tras OAuth. El efecto mostraba éxito siempre después de load(), incluso si acababa de devolver 401 por sesión caducada o error de red. Contradecía la alerta de autenticación y el fallo cerrado de REC-AUTH-211/212.

## Corrección
load() devuelve true exclusivamente cuando la consulta GET de Google finaliza correctamente y confirma connection.connected === true. Ante 401/403 o excepción devuelve false; el callback sólo muestra la confirmación positiva si la conexión fue verificada. No se altera OAuth ni se permite importar.

## Regresión
REC-AUTH-213: callback conectado, APIs 401, error login y cero mensaje de éxito. REC-AUTH-214: callback realmente confirmado mantiene el aviso positivo. Fixtures sintéticos; ningún POST ni escritura.

AP1–AP8 permanecen abiertos hasta CI y aceptación completas.
