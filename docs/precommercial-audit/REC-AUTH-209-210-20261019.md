# REC-AUTH-209/210 · frontera real en preview protegida

Fecha: 19/10/2026. PR #619 DRAFT; sin tocar producción ni el origen Google.

## Problema de cobertura
El workflow `Gate 4 Protected Workspace Boundary` estaba restringido a pushes en `commercial-readiness/**` y nunca se ejecutaba en la PR #619. Tras proteger el GET de metadatos Google y salud/sync no había una validación automática en preview real con el bypass de Vercel; el chequeo de Playwright en `Auth Session Regression` se ejecutaba contra aplicación local con datos sintéticos. El acceso desde el conector Vercel sin sesión devolvió 401 de *Vercel Protection*, que no certifica la respuesta de Financial App.

## Implementación y ejecución segura
Reutilizar el workflow existente, no duplicar. Sus triggers ahora incluyen PRs propios a main y a la base de PR #619 que cambian endpoints de fuente/auth o este test. Para un evento pull_request usar inmutable `github.event.pull_request.head.sha` en la búsqueda de deployments GitHub, checkout, comprobación /api/build y manifest; no usar `context.sha` ni `GITHUB_SHA` correspondientes al merge commit temporal. Excluir forks de la ejecución con secretos. GitHub Actions usa OIDC efímero o el bypass previamente configurado, sin imprimir credenciales.

REC-AUTH-209/210 comprueban GET reales de Google metadata, salud y último recibo SIN cookie propia (deben devolver 401 y JSON sin accountEmail, authMode, connection ni run). Se conservan PRE-003 y sus verificaciones previas; no se añade ningún POST nuevo ni se llama a operaciones bancarias. La preview debe corresponder al SHA de la rama, no basta READY para un SHA anterior.

## Aceptación
Exigir workflow CI del **SHA nuevo** y comprobar si GitHub ha registrado un deployment Vercel coincidente, además de pasar las pruebas. Si no puede resolverse el bypass OIDC o falta GitHub deployment, anotarlo como bloqueo y no fingir resultado. Las pruebas locales y la política RLS aún no reemplazan el caso de dos usuarios autenticados en nube segregada, OCR real y backup/restauración AP1–AP8.
