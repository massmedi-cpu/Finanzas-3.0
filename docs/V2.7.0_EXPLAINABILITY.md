# V2.7.0 — Explicabilidad

V2.7 hace visible la procedencia de una clasificación sin modificar la fuente bancaria.

## Prioridad canónica

1. División manual del movimiento.
2. Override manual de categoría/subcategoría/merchant.
3. Regla privada activa.
4. Dato de origen.

`resolveClassificationOrigin` implementa y prueba esta precedencia para la interfaz.

## Sugerencias

El motor sugiere únicamente comercios repetidos con una señal fuerte (>=3 movimientos y >=80 % de consistencia). No aplica cambios por sí mismo.

La creación desde una sugerencia tiene dos pasos obligatorios:
1. ejecutar preview real V2.6;
2. crear la regla solo con ese preview vigente.

## Superficie

`/explicabilidad` muestra la procedencia de los últimos 100 movimientos normalizados y los candidatos a automatización con evidencia. `finanzas-v3-explainability` permanece privado y falla cerrado si la sesión no se valida.
