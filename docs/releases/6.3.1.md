# Financial App 6.3.1

## Objetivo

Cerrar el caso documental pendiente de 6.3.0 sin modificar el motor de reconocimiento PP-OCRv6 ni degradar los tickets ya validados.

## Cambios

- Añadida reconstrucción específica para tablas comerciales `Cantidad / Código / Artículo / Precio / IVA / Subtotal`.
- Recuperación de líneas cuando OCR concatena cantidad y código, conservando el código dentro de la descripción estructurada.
- Normalización a céntimos de importes impresos con tres decimales.
- Validación de facturas con precios netos: suma de líneas contra base imponible y `Base + IVA` contra total.
- Revisión OCR canónica `paddle_layout_v5` para que los documentos procesados con la lógica anterior puedan reanalizarse.
- Regresión automatizada basada en el documento comercial que quedaba pendiente tras 6.3.0.

## Garantías

- El reconocimiento OCR sigue siendo una única inferencia PP-OCRv6.
- La evidencia literal y la geometría original permanecen intactas.
- La ruta específica de tickets no cambia.
- Ningún dato bancario ni documento de origen se modifica desde la aplicación.
