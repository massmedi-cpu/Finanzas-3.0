# Financial App 6.5.0

## Runtime visual más ligero y preparado para crecer

Financial App 6.5.0 da un salto de familia para retirar deuda transversal del runtime visual y desacoplar los gates históricos de una única rama de versión. No añade una nueva capa estética ni cambia los contratos financieros existentes.

### CSS global reducido

- Se elimina por completo `app/visual.css`, que ocupaba **3.292 bytes** y se cargaba desde el layout raíz en todas las rutas.
- El skeleton compartido `route-loading-v300` pasa a `app/route-loading.css`, conservando exactamente su responsive, shimmer y respeto a `prefers-reduced-motion`.
- Los tokens `--chart-*` dejan de existir en el root y pasan a `app/analisis/chart-tokens.css`, acotados a `.analysis-workspace` y con su variante dark local.
- Cash Flow mantiene sus reglas canónicas en `app/cash-flow.css`; Inicio también carga esa hoja porque reutiliza `CashFlowChart`.
- Cuentas conserva `BalanceChart` en `app/accounts.css` y Patrimonio conserva su gráfica en `app/net-worth.css`. No se crea un segundo sistema de gráficas.

### Análisis: mismo panel, menos coste de pintura

Los **24 gráficos e informes rápidos** de Análisis siguen disponibles, personalizables y en el mismo orden funcional. La rejilla aplica `content-visibility:auto` con tamaño intrínseco de reserva, permitiendo que el navegador difiera el layout/pintado de tarjetas fuera de pantalla hasta que se aproximen al viewport. Los navegadores sin soporte ignoran la optimización sin perder contenido.

### Gates de release preparados para siguientes familias

Los gates históricos desde 6.4.0 hasta 6.4.11 siguen ejecutándose y conservan sus verificaciones de seguridad, matching, Drive, previsión, edición múltiple, SQL y CSS. Su única modernización es el uso de un comparador semántico compartido `versionAtLeast`, para validar que la versión actual es igual o posterior a cada baseline en vez de exigir artificialmente `6.4.x`.

Esto permite 6.5.x, 6.6.x o futuras familias sin rebajar ninguna protección histórica.

### Contratos preservados

- La versión técnica npm permanece en **3.4.8**.
- No hay DDL en la release 6.5.0.
- No se modifican datos financieros ni documentos de origen.
- No se altera OCR, matching documental, Previsión ni sincronización de Google Drive.
- La release SQL es metadata-only y acepta como baseline de transición 6.4.11.
- La reconciliación autenticada de Drive continúa siendo una operación independiente del release.
