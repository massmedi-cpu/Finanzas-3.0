# Financial App 10.0.38 · CI de integridad de base de datos

Objetivo: retirar deuda operativa de ocho gates históricos de integridad de base de datos sin perder cobertura.

Cambios:
- Se sustituyen ocho workflows versionados 10.0.13–10.0.20 por equivalentes permanentes y version-agnostic.
- Se eliminan triggers `push` contra ramas `audit/...` históricas ya cerradas.
- Se conserva cada suite Playwright original y su ámbito de rutas/migraciones.
- Se añade `workflow_dispatch` a cada gate para poder certificarlo manualmente cuando sea necesario.
- Se retiran comprobaciones locales de versión duplicadas en gates de DB; la identidad de release ya está protegida por el gate canónico de release.
- Nuevo contrato `verify-db-ci-gates-10.0.38.mjs` que exige los ocho gates genéricos, sus ocho suites, ausencia de workflows legado y ausencia de ramas de versión muertas.
- Nuevo workflow agregado `DB Integrity Gates 10.0.38` que ejecuta contrato, TypeScript, build y las ocho regresiones.
- El gate agregado observa también `package.json` y `package-lock.json`, por lo que el HEAD final versionado se vuelve a certificar.

Versionado:
- `package.json` y `package-lock.json` sincronizados mediante `npm version 10.0.38 --no-git-tag-version`.
- El workflow temporal de versionado se autoeliminó del árbol final.
- La certificación inicial previa al versionado quedó completamente verde; el HEAD final se vuelve a ejecutar después de este cierre documental.

Alcance: no modifica lógica financiera, datos, migraciones, Supabase, OCR, autenticación, persistencia ni Vercel. Production permanece en 10.0.35.
