# Financial App 6.4.9

## Limpieza del alcance CSS

La 6.4.9 elimina una carga global innecesaria sin cambiar el diseño validado.

- `home.css` deja de cargarse desde el layout raíz y se carga únicamente en Inicio.
- `archive-review.css` deja de cargarse desde el layout raíz y se carga en el layout de Archivo, incluida su ruta de Revisión.
- Las reglas CSS no se reescriben ni se duplican: solo cambia dónde se importan.
- `document-linking.css` permanece global porque sus reglas se comparten entre Archivo y Movimientos.
- Se sacan 11.251 bytes de CSS específico del ámbito raíz, reduciendo contaminación entre pantallas y riesgo de colisiones futuras.
- No se toca ningún dato financiero, RPC, OCR, matching, Previsión ni sincronización de Google Drive.
- La versión npm permanece en 3.4.8.

El gate `audit-css-scope-v649.mjs` protege que estos estilos específicos no vuelvan al layout raíz y que sigan cargándose en sus rutas correctas.
