# Financial App 6.4.10

Release de limpieza medida del alcance CSS compartido, sin cambios funcionales ni de datos.

## Qué cambia

- `document-linking.css` deja de importarse desde el layout raíz.
- Archivo y Movimientos lo cargan desde sus layouts propios, que son las dos únicas superficies que consumen sus selectores.
- Se retiran **2.083 bytes** de CSS del ámbito global de rutas que no enlazan documentos, incluida la pantalla de login y el resto de módulos.
- El gate histórico 6.4.9 queda forward-compatible: acepta el estado original global o el nuevo estado acotado, mientras 6.4.10 exige ya el aislamiento.
- La versión técnica npm permanece en **3.4.8**.

## Invariantes

- No se duplica ni reescribe `document-linking.css`.
- Archivo conserva `.archive-manual-link` y Movimientos conserva `.movement-documents` sobre la misma hoja compartida.
- No cambian RPC, matching documental, OCR, previsión, sincronización, permisos ni datos financieros.
- Google Drive y las fuentes bancarias continúan siendo solo lectura.
