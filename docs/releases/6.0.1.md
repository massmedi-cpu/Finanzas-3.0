# Financial App 6.0.1

Release de mantenimiento posterior a 6.0.0.

## Mejoras

- Archivo usa paginación en servidor para Nuevas, Pendientes y Archivadas.
- Búsqueda y conteos de Archivo comparten el mismo filtro y dejan de depender del límite de 200 documentos.
- Conciliación avanzada, documentos asociados y divisiones respetan tipografía mínima de 14 px y controles de 44 px.
- El sistema visual deja de usar aliases de compatibilidad y consume directamente tokens semánticos.
- Se retira el runtime específico de autenticación de previews.
- La validación continúa mediante GitHub CI y la publicación desde main se comprueba mediante smoke de producción por versión.

## Integridad

La migración de Archivo modifica funciones de lectura y paginación. La migración de release solo alinea los metadatos de versión. No modifican movimientos, importes, cuentas, documentos ni asociaciones.

La comprobación antes y después del contrato de Archivo mantiene 3.150 movimientos, suma 187.943,86 €, 2 cuentas, 119 documentos y 84 vínculos, con las mismas huellas de movimientos y documentos.

## Retorno

El punto de retorno estable permanece en `checkpoint/v6.0.0-production`.
