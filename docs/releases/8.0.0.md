# Financial App 8.0.0 · Simulador de Decisiones

Financial App 8.0.0 añade un simulador financiero efímero construido directamente sobre la Agenda Financiera Inteligente 7.0.0.

## Qué incorpora

- Nueva ruta `/escenarios`, accesible desde **Más → Simulador**.
- Simulación combinada de gasto puntual, ingreso puntual, gasto recurrente y compra a plazos.
- Hasta 24 definiciones por escenario y 120 impactos expandidos.
- Comparación de la previsión actual frente al escenario en un horizonte de 90 días.
- Saldo final, saldo mínimo, fecha del mínimo, días bajo cero y primera fecha de riesgo.
- Hitos de saldo a 30, 60 y 90 días.
- Gráfica comparativa y tabla diaria accesible.
- Calendario de impactos hipotéticos incluidos.

## Contrato financiero

El simulador no crea un segundo motor de previsión. `forecast_scenario_core` reutiliza `forecast_liquidity_core`, introducido en 7.0.0, y superpone únicamente los impactos hipotéticos recibidos en la petición.

Los escenarios son estrictamente efímeros: no se insertan, actualizan ni eliminan movimientos, cuentas, documentos, previsiones o saldos. No se usa `localStorage`, `sessionStorage` ni cookies para conservar hipótesis o resultados.

La fuente financiera original continúa siendo de solo lectura.

## Seguridad

- Core privado `financial_app.forecast_scenario_core(...)` con autorización explícita.
- Wrapper público `public.financial_app_forecast_scenario(...)` como `SECURITY INVOKER`.
- `anon` no puede ejecutar el RPC.
- `authenticated` y `service_role` conservan el grant explícito requerido.
- API `/api/scenarios` exige usuario autorizado y aplica límites de entrada antes de llamar al RPC.

## Compatibilidad

- Baseline funcional requerida: Financial App 7.0.0.
- La versión visible de producto pasa a **8.0.0**.
- La versión técnica npm permanece deliberadamente en **3.4.8**.
- No se modifica el flujo de Drive, OCR, matching documental, edición masiva, forecast canónico ni datos de origen.
