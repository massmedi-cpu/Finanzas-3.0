# Finanzas 3.0 — V3.0.0

## Objetivo
V3.0.0 consolida la evolución 2.1–2.9 en una base profesional, normalizada, auditable, reversible y preparada para producción.

## Capacidades consolidadas
- Modelo normalizado con sincronización idempotente y checksum de fuente.
- Analítica SQL compacta para informes, presupuestos, revisión, plan y previsión.
- Horizonte predictivo de hasta 60 meses y escenarios comparables.
- Objetivos inteligentes y prioridades financieras explicables.
- Cierre mensual persistente, reabrible y con detección de drift.
- Reglas privadas de clasificación con preview y precedencia manual.
- Explicabilidad de clasificación y sugerencias conservadoras de reglas.
- Centro de Control con auditorías persistentes.
- Backup/exportación y restauración atómica de la capa privada.

## Seguridad V3.0
Las funciones históricas `finanzas-v3-data`, `finanzas-v3-recurring` y `finanzas-v3-splits` pasan a autenticación fail-closed. El probe legado solo se considera válido con respuesta 2xx o el 404 autenticado esperado; 401/403, 5xx y fallos de red deniegan acceso.

Las tablas privadas mantienen RLS deny-by-default y el acceso funcional se realiza exclusivamente desde Edge Functions mediante service role interno. La service role no se expone al navegador ni al repositorio.

## Fuente y reversibilidad
La fuente bancaria continúa siendo solo lectura. Overrides, splits, presupuestos, reglas, objetivos, cierres, escenarios, auditorías y backups forman una capa privada independiente. El backup V2.9 no contiene la fuente bancaria y la restauración exige compatibilidad de checksum y referencias.

## Rendimiento
Las superficies principales no pueden volver a `loadValidatedSource`. Movimientos usa paginación/cursor y la analítica se resuelve mediante agregados SQL. El gate V3.0 conserva estas invariantes.

## Rollback
El checkpoint previo a release se conserva en `checkpoint/v3.0.0-pre-release`. La promoción final solo se realiza tras CI, preview Vercel exacto y verificación de producción.
