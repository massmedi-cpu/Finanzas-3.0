# Finanzas 3.0 V1.5.0

V1.5.0 incorpora gobierno manual sobre la detección de recurrentes.

La detección automática sigue partiendo del histórico real, pero ahora cada patrón puede confirmarse, ignorarse o corregirse. Las decisiones se guardan de forma privada, quedan separadas de la fuente bancaria y pasan a gobernar las previsiones del dashboard y del calendario financiero.

No se escriben cambios en Google Sheets ni se copian credenciales al repositorio.
