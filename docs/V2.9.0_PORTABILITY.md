# V2.9.0 — Portabilidad y recuperación privada

## Objetivo

Permitir exportar, guardar, verificar y restaurar exclusivamente la capa privada de trabajo de Finanzas 3.0 sin duplicar ni modificar la fuente bancaria original.

## Contenido del backup

El formato `finanzas-private-backup`, esquema 1, conserva:

- overrides manuales de movimientos;
- divisiones de movimientos;
- presupuestos;
- preferencias de recurrentes;
- objetivos;
- eventos futuros;
- escenarios;
- cierres mensuales;
- reglas privadas de clasificación.

La fuente bancaria, el snapshot bancario y las tablas normalizadas derivadas no forman parte del backup portátil.

## Garantías de restauración

Una restauración solo puede continuar cuando:

1. el formato y la versión de esquema son compatibles;
2. el checksum de la fuente coincide con el actual;
3. el número de movimientos corresponde al mismo snapshot;
4. no existen referencias a movimientos inexistentes;
5. el usuario ha visto el preview;
6. existe confirmación explícita `RESTAURAR`;
7. el reemplazo completo puede ejecutarse dentro de una única transacción PostgreSQL.

Si falla cualquier comprobación, no se aplica una restauración parcial.

## Evidencia V2.9

- Snapshot actual: 3.135 movimientos.
- Preview real de backup: `safe=true`.
- Checksum de backup y fuente actual: idénticos.
- Referencias inválidas: 0.
- Prueba round-trip PostgreSQL: modificación temporal → restauración → igualdad exacta de la capa privada → rollback de la prueba.

## Seguridad

`finance_v3_private_backups` usa RLS deny-by-default. La Edge Function `finanzas-v3-backup` conserva la service role solo en Supabase y exige la sesión privada antes de cualquier lectura o escritura.
