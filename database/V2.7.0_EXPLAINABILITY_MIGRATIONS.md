# V2.7.0 — Explicabilidad y sugerencias

## Cambios de base de datos

- `finance_v270_rule_suggestions(text, integer)` genera candidatos conservadores a reglas privadas.
- Solo considera movimientos presentes, sin override manual y sin regla activa aplicada.
- Excluye traspasos internos.
- Requiere al menos 3 coincidencias y una categoría dominante >= 80 %.
- Devuelve evidencia (hasta 5 movimientos), dirección, categoría/subcategoría sugeridas y confianza.
- No escribe reglas ni movimientos.
- `EXECUTE` está revocado para `PUBLIC`, `anon` y `authenticated`; solo `service_role` puede invocarla directamente.

## Regla de seguridad

Una sugerencia nunca se transforma directamente en clasificación. La UI obliga a ejecutar primero `finance_v260_rule_preview`; solo después puede guardarse una regla V2.6.
