# V2.8.0 — Control migrations

Cambios aplicados de forma aditiva en Supabase:

- tabla `finance_v3_system_audits` para checkpoints de auditoría;
- RLS habilitado y acceso directo revocado para `PUBLIC`, `anon` y `authenticated`;
- índice temporal para historial por propietario;
- RPC `finance_v280_system_snapshot` para construir un snapshot consistente de estado, calidad, automatización y capa privada;
- Edge Function `finanzas-v3-control` como única puerta de lectura/escritura desde la aplicación.

La migración no modifica la fuente bancaria ni las filas normalizadas. Los checkpoints son observacionales y append-only desde la experiencia de usuario.
